# Задание на выгрузку из keywordtool.io

Дата: 06.09.2026. Зачем: GSC показывает только запросы, где сайт уже появляется в выдаче.
Спрос, по которому у сайта нет ни одной позиции, в нём не виден вообще. Эта выгрузка закрывает дыру.

## Общие настройки

- Источник: **Google** (не YouTube, не Amazon).
- Экспортировать вкладки: **Keyword Suggestions** и **Questions**. Вопросы нужны отдельно —
  из них делаются H2 и блоки FAQ, и именно они попадают в ответы ИИ-систем.
- Колонки: ключ, search volume, trend, CPC, competition. Формат — CSV или XLSX, без разницы.
- Файлы называть по группе: `kw-geo-ru.csv`, `kw-nisze-ru.csv` и так далее. Класть в `drafts/`.
- Если у тарифа есть лимит на выгрузку — приоритет групп: 3, 2, 4, 1, 5, 6.

Важно про язык и страну: keywordtool считает объёмы по паре «язык + страна».
Русскоязычные группы прогнать **дважды** — Country: Poland и Country: Russia. Объёмы будут
разными, и разница сама по себе информативна: она показывает, где сидит аудитория.

## Что я сделаю с этими файлами

1. Сведу с выгрузкой GSC: по каждому ключу будет видно, есть ли уже показы и на какой позиции.
2. Помечу, какая страница сайта отвечает за ключ — и есть ли она вообще.
3. Выдам список дыр, отсортированный по объёму, с пометкой, где домен реально может конкурировать,
   а где это головной запрос вроде «стоимость продвижения сайта», который при пяти ссылающихся
   доменах не берётся ничем.

## Чего от этих данных НЕ стоит ждать

Объёмы keywordtool — это оценки на основе данных Google Ads, а не факт. Для русскоязычных запросов,
которые обслуживаются за пределами России, они особенно приблизительны. Пользоваться ими имеет смысл
для сравнения ниш между собой, а не как абсолютными числами. Ноль в колонке объёма не означает,
что запроса не существует: у нас есть ключи с реальными показами в GSC, которым инструменты
рисуют нулевой объём.
